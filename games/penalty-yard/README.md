# Дворовые пенальти · прототип 0.2

Этап 2: локальная проверка удара и управляемого вратаря. Это тренировочный прототип, а не готовый сетевой матч. Графика из простых фигур — временная.

## Запуск на Windows

1. Скачайте репозиторий: **Code → Download ZIP**. Распакуйте архив.
2. Откройте папку `games/penalty-yard`.
3. Запустите `StartGame.bat` двойным щелчком.

При первом запуске нужен интернет: скрипт скачивает официальный Godot 4.5.1 (около 73 МБ), проверяет SHA-512 и сохраняет движок в `.engine`. Установка редактора и права администратора не нужны. Следующие запуски работают без загрузки движка.

Другой способ: открыть `project.godot` в Godot **4.5.1 Standard**, затем нажать **F6** для сцены или **F5** для проекта. Версия .NET не требуется.

На Linux/macOS: Godot 4.5.1 Standard, открыть `project.godot` и нажать F5.

## Что доступно

- Тренировка бьющего по пустым воротам: направление, заряд силы и подкрутка.
- Тренировка вратаря: пять повторяющихся типов заданных ударов, движение, руки, окно ловли и один рывок на попытку.
- Счёт результатов тренировки, пауза, повтор попытки, звуки и след полёта мяча.
- Пересечение линии всем мячом, столкновения с рамой и землёй, отскоки и ограничения досягаемости рук.

Удары вратарю идут в фиксированной последовательности, чтобы можно было повторять и сравнивать спасения. Онлайн, строительство, магазин и полный матч появятся в следующих этапах.

## Управление

| Клавиша | Действие |
|---|---|
| 1 / 2 | Переключить роль |
| R | Сбросить попытку; результаты предыдущих попыток сохраняются |
| Esc | Пауза / продолжить |
| Мышь | Направление удара или положение рук |
| ЛКМ, удержать и отпустить | Зарядить силу и ударить в режиме бьющего |
| ПКМ | Отменить подготовку удара |
| Q / E | Убавить / прибавить подкрутку: влево, без подкрутки, вправо |
| ЛКМ в режиме вратаря | Начать двухсекундный отсчёт; после удара — попытаться поймать |
| A / D | Двигаться вдоль ворот |
| Space + A / D | Один рывок на попытку |

Зелёная точка показывает исходный прицел. Подкрутка и отскоки могут изменить итоговую точку. Вратарь ловит коротким нажатием, когда мяч рядом с руками; постоянное удержание не продлевает ловлю. Движение A/D соответствует направлению на экране.

## Что проверить Эльдару

1. Пять прямых ударов с разной силой: понятно ли, куда летит мяч?
2. Удары с подкруткой: можно ли осознанно выбрать угол?
3. Несколько попыток вратаря: виден ли мяч, удобно ли ставить руки, удаётся ли поймать после повторения?
4. Рывок: помогает ли он или слишком резко переносит камеру?
5. Есть ли желание повторять попытки без наград?

Игровые ощущения и баланс пока не подтверждены людьми. Сборка Windows требует пользовательской проверки; автоматические проверки выполнены в Linux/Godot.

## Разработка и проверки

Настройки: `scripts/tuning.gd`. Правила гола и ловли: `scripts/rules.gd`. Мяч: `scripts/ball.gd`. Площадка: `scripts/yard.gd`. Тренировка и интерфейс: `scripts/game.gd`.

Из этой папки, с Godot в PATH:

```sh
godot --headless --editor --import
godot --headless --script tests/test_rules.gd
godot --headless --script tests/test_game.gd
```

Godot иногда возвращает код 0 при ошибке импорта: также проверяйте вывод на `SCRIPT ERROR` и `ERROR`. В CI это проверяется автоматически. Тесты проверяют правила и фактическую 3D-сцену, а не субъективную увлекательность.
