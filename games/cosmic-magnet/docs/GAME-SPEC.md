# Cosmic Magnet — требования v0.1

## Цель и границы

Быстро выпустить небольшую законченную игру с приятным сбором, ощутимой прокачкой и финалом. Потенциал продаж — гипотеза, которую проверяем прототипом и публичным показом. Целевая продолжительность готовой версии 90–120 минут, но не достигаем её искусственным ожиданием.

Один экран свалки, один магнит, один игрок, мышь. Один основной ресурс — лом. Сбор → разгрузка/конвертация в лом → покупка улучшения → более тяжёлая добыча. Финальная цель — поднять большой корабль. Исключены кооператив, бой, открытый мир, строительство базы, реалистичная орбитальная физика, платные лутбоксы и мобильный релиз.

## Требования

| ID | Поведение |
|---|---|
| CM-R01 | Магнит следует за мышью внутри игровой области; интерфейс не является игровой областью. Пауза/потеря фокуса останавливают симуляцию. |
| CM-R02 | В пределах радиуса предмет с `required_strength <= strength` плавно притягивается. Тяжёлый предмет остаётся на месте и показывает требуемую силу. |
| CM-R03 | При достижении радиуса захвата предмет удаляется и записывается в груз ровно один раз. Вне радиуса предмет не собирается. |
| CM-R04 | В состоянии SALVAGE тратится заряд. Если заряда нет или трюм заполнен, происходит переход в DOCK и автоматическая разгрузка без потери добычи. Есть кнопка досрочной разгрузки. |
| CM-R05 | Разгрузка один раз начисляет стоимость груза, очищает груз и восстанавливает заряд. Игрок нажимает «Вылет», чтобы продолжить. Повторные сигналы разгрузки не начисляют деньги повторно. |
| CM-R06 | В DOCK доступны сила, радиус, ёмкость и позднее улучшения заряда/эффективности. Недостаток лома или максимальный уровень блокируют покупку. Деньги и уровень изменяются одной операцией. |
| CM-R07 | HUD отражает текущий лом, заряд, груз и уровни; в SALVAGE покупки отключены. Все действия UI не перемещают магнит. |
| CM-R08 | Свободная свалка пополняется ограниченным числом обычных предметов; запас не может закончиться навсегда. Уникальные находки не возрождаются после сбора. |
| CM-R09 | Финальный корабль виден с начала, доступен при силе 12. При сборе показывает финальную сцену и итог, затем сохраняет завершение. Достижение 12 должно быть возможно обычным сбором. |
| CM-R10 | Сохранение уровней, лома, настроек, уникальных находок, финального состояния; загрузка возвращает игрока в безопасный DOCK. Сохранение при покупке, разгрузке, важной находке и штатном выходе. |
| CM-R11 | Закрытие посреди вылета не начисляет незавершённый груз; ранее выгруженный лом не теряется. Пауза останавливает заряд и движение. Новая игра требует подтверждения. |
| CM-R12 | Файл сохранения имеет версию, валидируется, записывается через временный файл с восстановлением из резервной копии. Некорректный файл не приводит к падению или тихой потере единственной копии. |
| CM-R13 | Окно от 1280×720 до 1920×1080, масштабирование без обрезания HUD. RU/EN, отдельные музыка/эффекты, оконный/полноэкранный режим. |
| CM-R14 | Windows x64-сборка запускается без установленного редактора. Ориентир — 60 FPS при 150 предметах; доказательство включает оборудование и длительность замера. |

## Модель состояния

`DOCK → SALVAGE → DOCK`, дополнительная PAUSED с возвратом в предыдущее состояние, COMPLETED после корабля. Магнит не двигается в DOCK; UI полностью доступен. Первая загрузка новой игры может сразу запустить обучающий SALVAGE. Энергия и груз появляются только в CM-002, чтобы CM-001 оставался минимальным.

Притяжение — управляемое движение Node2D по `delta`, с ограничением скорости и проверкой пересечения радиуса захвата на большом шаге. Не требуется физический симулятор столкновений всех обломков. Спавн исключает область UI и захвата магнита; число предметов ограничено. Удаление/начисление проходит через единственный обработчик сбора.

## Исходные числа CM-002: гипотезы для настройки

| Настройка | Значение |
|---|---:|
| Сила | 1, максимальная 12 |
| Радиус притяжения | 100 условных единиц игрового пространства |
| Радиус захвата | 12 единиц |
| Заряд | 45 секунд вылета |
| Ёмкость | 30 единиц массы |
| Обычные предметы одновременно | 40, максимальная граница 150 |

Первые предметы: гайка (сила 1, масса 1, цена 1), пластина (1/2/3), аккумулятор (2/4/8). Груз не превышает ёмкость: слишком большой предмет остаётся на поле; при полном трюме — разгрузка. Всегда спавнятся доступные гайки; нельзя заблокировать прогресс покупкой одного направления.

Первые улучшения: сила 1→2 стоит 20 лома; радиус +20 стоит 15; ёмкость +10 стоит 15. Следующие уровни используют `ceil(base_cost × multiplier ^ bought_levels)` с явно указанным множителем и ограничением уровня в конфиге. Для CM-002 достаточно трёх уровней в каждом направлении. Полная кривая до силы 12 проектируется и проверяется в CM-006, а не объявляется уже сбалансированной.

Первая покупка должна быть достижима за 60–120 секунд обычной игры; новая сила открывает узнаваемый предмет. Поздняя прокачка добавляет механические изменения: цепное притяжение соседних доступных предметов и небольшой автоматический сборщик. Они входят только в CM-006 после принятия основной петли; не реализовать заранее.

## Графика и звук

Ориентир: `games/cosmic-magnet/assets/reference/concept.png` от корня репозитория. Тёмный синий фон, бирюзовое притяжение, янтарные акценты, читаемые силуэты. Панель улучшений справа, HUD сверху, поле слева. CM-001 использует простые честные заглушки. В CM-005 — отдельные спрайты, единый масштаб пикселей, приятное движение и звук. Большой корабль нельзя просто вырезать из концепта вместе с фоном.

## Техническая структура (ориентир)

`project.godot`, `scenes/main.tscn`, `scripts/` (game, magnet, salvage_item, spawner, economy, save_service по мере необходимости), `data/balance.json`, `assets/`, `tests/`, `docs/reports/`. Не создавать пустую архитектуру на будущее. UI использует Containers/anchors и отделён от пространства игры.

Сохранения: `user://cosmic_magnet/save_v1.json`; конфиг репозитория — источник стартового баланса. Тесты используют отдельный временный профиль, не сохранение игрока. Никакой зависимости от соседней игры.
