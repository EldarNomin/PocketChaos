# Первое задание GLM

Скопировать исполнителю после `git pull`:

> Ты реализуешь «Космический магнит» в `EldarNomin/PocketChaos`, папка `games/cosmic-magnet`. Это отдельная 2D-игра Godot 4.5.1 Standard/GDScript. Прочитай AGENTS.md, README и все документы games/cosmic-magnet/docs. Выполни только CM-001 из DEVELOPMENT-PLAN.md. Создай ветку feat/cosmic-magnet/CM-001-baseline от актуального main. Нужен запускаемый проект: магнит следует за мышью в поле, предметы плавно притягиваются, собираются ровно один раз, счётчик обновляется, пополнение ограничено. Сначала простые заглушки, без магазина, энергии, полного арта, сохранений и Steam. Добавь небольшой headless-тест правил сбора и отдельный CI workflow. Проверь импорт, smoke и тесты, запиши точные результаты. Запиши 20–30 секунд реального геймплея; если запись недоступна, честно укажи NOT_RUN. Обнови STATUS до READY_FOR_REVIEW и приложи отчёт по REVIEW.md. Открой небольшой PR в main, не сливай его сам. Остановись на сдаче CM-001 и жди решения Codex. Не реализовывай другие этапы заранее.

После сдачи сообщить Эльдару URL PR и SHA. Эльдар передаёт Codex: «Проверь CM-001, PR <URL>». Codex сверяет задачу, код, CI и доказательства, при необходимости пишет конкретное задание исправлений. Следующий этап выдаётся в STATUS/отчёте только после приёмки.

Если у GLM есть только доступ к Unity: не создавать Unity-проект внутри этой папки. Нужен запуск Godot через CLI/редактор; при отсутствии сообщить точный блокер.
