# PocketChaos

Небольшие игры с понятными правилами, физикой и поводом для реванша.

Первый проект: **Дворовые пенальти** — дуэль на двоих с изменяемой площадкой.

Разработка идёт по этапам: правила → удар и ловля → онлайн → препятствия → оформление.

## Дворовые пенальти

**Доступен прототип 0.4:** онлайн-дуэль с общим полем, щитами и вентиляторами. Пять парных раундов, смена ролей, общий счёт и реванш. Предметы можно попробовать в локальной тренировке.

- [Запуск и управление](games/penalty-yard/README.md)
- [ТЗ, спецификации и все этапы](docs/penalty-yard-specification.md)
- [Исходные правила этапа 1](docs/penalty-yard-stage-1.md)
- Windows: скачать ZIP репозитория, распаковать и запустить `games/penalty-yard/StartGame.bat`.
- Godot 4.5.1 Standard: открыть `games/penalty-yard/project.godot` и нажать F5.

Графика временная. Следующий этап — игровые пробы, настройка баланса и один оформленный двор. Подключение сейчас прямое по IP; приглашения и соединение через Steam пока не добавлены.
